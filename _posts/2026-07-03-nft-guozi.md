## 国资问题

国资的作用就是按照党中央制定的方向、国务院和国家发改委的主要投资与规划，以及省级发改委（在省政府）在土地审批、本地能源基础设施等方面的配合，来设计项目机会。有了项目再和各级政府商量如何符合项目资本的需求，最终负责项目的完成。国资会参与多轮项目，也会连续和各级政府以及伙伴合作。

每一次项目成功，下一轮就更顺利。项目和五年计划吻合，对接更自然。国资的信任很重要。

我们以下举个例子，分析相关刚出的十五五计划。

### 例如项目：内蒙古自治区AI算力城

按照十五五计划建立一个国际级算力中心（10亿瓦级）。

![建立计算城](/assets/images/2026-07-03-nft-guozi.webp)

我们先分析在内蒙古自治区该项目的需求：

- 🟢 地面
- 🟢 矿场的煤炭
- 🟢 发电厂（10亿瓦级）
- 🟢 算力城外壳设计
- 🟢 算力城外壳建立（包电力、电池、散热，外网）
- 🟢 算力城内网络（服务器与服务器）
- 🟠 了解应用需求
- 🟠 服务器
- 🟠 AI芯片

在国外类似资本需求大约500亿美元（房地产、建设、发电厂、服务器、芯片）。在国内估计会便宜一些，但是实现该项目会需要国资和省、市政府以及其他方大力支持。

ℹ️ 关心点：以上的资本需求大大大量在于**🟠服务器**和**🟠AI芯片**。

## 国资和私资对比

我已经分析过如何在内蒙古自治区建立算力中心。蒙古国私立、内蒙古自治区私立和内蒙古自治区国资项目都不同。以下对比项目**基础**：

| | 蒙古国私立 | 内蒙古自治区私立 | 内蒙古自治区国资 |
| -------------------------------------------- | ---------------------------- | ---------------------------- | ---------------------------- |
| 🟢 地面 | ❌ 不能保证 | ❌ 不能保证 | ✅ 可保证 |
| 🟢 矿场的煤炭 | ✅ 可以买 | ❌ 不能保证 | ✅ 可保证 |
| 🟢 发电厂 | ❌ 不能保证 | ❌ 不能保证 | ✅ 可保证 |
| 🟢 算力城外壳设计 | ✅ 可以做 | ❌ 不能保证 | ✅ 可保证 |
| 🟢 算力城外壳建立（包电力、电池、散热，外网） | ✅ 可以做 | ❌ 不能保证 | ✅ 可保证 |
| 🟢 算力城内网络 | ✅ 可以做 | ✅ 可以做 | ✅ 可保证 |

剩下的算力部分更难说：

| | 蒙古国私立 | 内蒙古自治区私立 | 内蒙古自治区国资 |
| -------------- | --------------------------- | ---------------------------- | --------------------------- |
| 🟠 了解应用需求 | ✅ 懂得多 | ✅ 懂得多 | ❓ 可问企业 |
| 🟠 服务器 | ✅ 可以买 | ✅ 可以买 | ✅ 用国内的 |
| 🟠 AI芯片 | ✅ 用国外的 | ❓ | ✅ 用国内的 |

项目的**基础**国资十分可以做得到。**私立资本无法保证项目实现。**

国资自己买**服务器**和**AI芯片**有可能买错款。还有这一部分是大大大量资本需求。

到这一点我们可以分析相关思路如何帮助国资实现项目难点，还有西方常见做法和中国内实际应用怎么不一样。

## 如何用相关思路帮助项目

目前的困难是：

- 最终算力城要符合企业实际算力需求。
- 资本参与方需要确信项目能够顺利实现。
- **服务器**和**AI芯片**需求可能比国资提出过类似的项目更大。

还有不要忘记国资强项：

- 只有国资能保证各级政府（省、市等）的合作。
- 国资获得面积、发电证和别的证都不紧。
- AI大算力是十五五计划的目标企业。
- 国资能带来很多企业方，介绍新的合作方式。

RWA相关思路可以带来一个更合适的资本方式。可能更适合该项目。我们先对比几种资本方式：

| 投资 | 贷款/债券 | ⭐️ 容量权利 |
| -------------- | -------------- | ------------------ |
| 项目成功后分红 | 项目还在发利息 | 项目实现后有权入驻 |

我们可以想象算力城是一个多横多竖的格子。

| 1号位置 | 2号位置 | 3号位置 | 4号位置 | 5号位置 |
| ------------ | ------------ | ------- | ------- | ------- |
| 。。。。。。 | 。。。。。。 | | | |
| | | | | |
| | | | | |
| | | | | |

每一个格子有一定的面积、一定的电力容量、一定的内外网、一定的散热限制。

如果国资已经通过所有的面积、发电、类似的证，那就可以提前明确这些位置的入驻权利。项目建立好之后，谁持有该权利，就有权利入驻。

**⭐️ 持有方提供自己的服务器和 AI 芯片。入驻后仍需支付房租和电费。**

这些入驻权利可以按市场价格分配给实际需要算力的企业方。

这种资本方式可以带来大量早期的资本，也会减少国资的风险。

**⭐️ 通过这种方式，参与方为什么最相信项目会实现？因为政府方实现之后，政府方还可以继续赚房租和电费。**

为什么需要允许这些权利在一定规则下转移？

因为光速限制，高带宽AI计算对物理位置非常敏感。相邻的几个房间一起用，效率远高于分散的房间。持有1、2、3号位置比持有1、2、5号位置有用得多。早期预订的企业可能是大型用户，也可能是刚起步的公司。从预订到实际搬入，中间市场情况会变化，需要一个清晰的登记和调整机制，让最终真正使用的运营主体能坐到合适的位置。

这些权利本身不附带分红，也不能当金融产品转租赚钱。它们只给实际运营实体使用，目的就是把物理容量分配清楚。

2026年2月银发〔2026〕42号等文件对境内RWA代币化活动做了明确限制。但国资在研究十五五重大项目的资本和风险安排时，仍然可以认真分析这类机制的有用属性，并在自己的内部系统和合规框架下设计类似的容量分配方式。

西方常见的RWA做法和中国实际可用的方式不一样：

| 西方常见做法 | 中国实际可用方式 |
| ----------------- | ---------------- |
| 容易金融化、二级市场炒作 | 政府可以严格控制 |
| 匿名参与 | 必须可追溯、可审核 |
| 和去中心化金融深度绑定 | 可以绑定人民币和内部登记系统 |

除了技术以外，私立公司更喜欢高风险项目。他们不依赖政府贷款和这种容量权利模式。他们会到各个国家参与证券交易。国资的风险偏好不同，因此这种更可控的方式可能更适合。
